We built Eunoia to bring them together:
• Native D2 code compilation into interactive, editable canvas elements
• 60 FPS continuous pan & zoom with 3,000+ vector shapes
• Sub-50ms multiplayer peer sync with isolated per-user undo/redo
• Vector PDF, SVG, and animated history GIF export
• Open source Community Edition + Cloud Pro
