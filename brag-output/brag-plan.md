# Brag Plan: Eunoia

## What is this app?

Eunoia is a high-performance, real-time collaborative whiteboard engine designed for engineering teams that natively compiles D2 diagram code into interactive canvas objects — 60 FPS at 3,000+ shapes, sub-50ms peer sync via Yjs CRDTs, and zero data loss.

## The angle

Quiet engineering confidence. This isn't a fluffy marketing pitch — it is the tool engineering teams actually switch to. The video demonstrates the core workflow outlined in the showcase script: drawing freely on an infinite canvas with smart magnetic connectors, writing D2 code and using AI prompts to instantly compile native interactive vector objects, collaborating in real-time with live remote cursors and isolated undo/redo, and exporting to vector PDF and timelapse GIF.

## User flow worth showing

1. **Entry**: Open a room on the infinite canvas with tools, grid, and minimap.
2. **Key Action**: Write D2 code or describe with AI in Monaco editor; watch it compile into native editable vector elements.
3. **Collaboration & Export**: Multiplayer cursors move in real time with sub-50ms sync, isolated undo/redo, and high-res vector/PDF export.
